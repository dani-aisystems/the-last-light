## Документация на проекта (публично копие)

Публичното копие е еднакво по съдържание с предаваната документация, но личните полета (телефони, имейли, училище, клас, ръководител) са заменени с препратка към регистрационния формуляр, а разпределението на ролите и използваните външни инструменти са препратени към Декларацията (Приложение 4), която е в предадената папка. Оригиналните `.docx` файлове се пазат отделно и не са променяни.

## Съответствие с изискванията на регламента

Само изискванията, които са записани в регламента:

| Изискване (Регламент, раздел „Изисквания за участие“) | Състояние |
|---|---|
| Изходен код (задължителен) | Публикуван в хранилището и като архив с контролна сума |
| Изпълним код | macOS: изпитан на Apple M3; Windows: експортиран, **не е изпитан** на Windows |
| Документация до пет листа А4 и рекламна диплянка | Налични (виж таблицата по-горе) |
| Декларация за лицензиран или свободно разпространяван софтуер (Приложение 4) | Подава се от автора в предадената папка; не е публикувана тук |
| Качване на материалите в интернет и споделена връзка | Този GitHub адрес и Google Drive папката на участието |

Този указател не заменя регламента. При различие важи официалният документ.
